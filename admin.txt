Admin API Endpoints and Data Requirements
Base URL: http://localhost:5000/api
Note: All endpoints require an httpOnly cookie "accessToken" obtained from the Login endpoint and the user must have the "admin" role.

--- USER MANAGEMENT ---

1. Get All Students
   - Method: GET
   - Endpoint: /students
   - Description: Lists all users with the role "student".
   - Request Body: None

2. Get All Mentors
   - Method: GET
   - Endpoint: /mentors
   - Description: Lists all users with the role "mentor".
   - Request Body: None

3. Get Student By ID
   - Method: GET
   - Endpoint: /students/:id
   - Path Param: id (User ID)
   - Description: Get details of a specific student.
   - Request Body: None

4. Get Mentor By ID
   - Method: GET
   - Endpoint: /mentors/:id
   - Path Param: id (User ID)
   - Description: Get details of a specific mentor.
   - Request Body: None

5. Update User Status
   - Method: PUT
   - Endpoint: /update-status/:id
   - Path Param: id (User ID)
   - Description: Update the status of a user (e.g., active, suspended).
   - Request Body:
     {
       "status": "active" // "active" or "suspended"
     }

6. Get Users By Role
   - Method: GET
   - Endpoint: /getUsersByRole/:role
   - Path Param: role ("student" or "mentor")
   - Description: Lists all users with the specified role.
   - Request Body: None

7. Activate User
   - Method: PUT
   - Endpoint: /activate/:id
   - Path Param: id (User ID)
   - Description: Set user's isActive flag to true.
   - Request Body: None

8. Deactivate User
   - Method: PUT
   - Endpoint: /deactivate/:id
   - Path Param: id (User ID)
   - Description: Set user's isActive flag to false.
   - Request Body: None

9. Delete User
   - Method: DELETE
   - Endpoint: /delete/:id
   - Path Param: id (User ID)
   - Description: Permanently delete a user.
   - Request Body: None

--- ASSIGNMENTS ---

10. Create Assignment
    - Method: POST
    - Endpoint: /assignments
    - Description: Create a new assignment.
    - Request Body:
      {
        "title": "React Basics",
        "skillId": "65a...",
        "dueDate": "2023-11-01T23:59:59Z",
        "maxScore": 100
      }

11. Get All Assignments
    - Method: GET
    - Endpoint: /assignments
    - Description: Lists all available assignments.
    - Request Body: None

12. Get Assignment By ID
    - Method: GET
    - Endpoint: /assignments/:id
    - Path Param: id (Assignment ID)
    - Description: Get details of a specific assignment.
    - Request Body: None

13. Update Assignment
    - Method: PATCH
    - Endpoint: /assignments/:id
    - Path Param: id (Assignment ID)
    - Description: Update an existing assignment.
    - Request Body:
      {
        "title": "React Advanced",     // Optional
        "dueDate": "2023-11-05"        // Optional
      }

14. Delete Assignment
    - Method: DELETE
    - Endpoint: /assignments/:id
    - Path Param: id (Assignment ID)
    - Description: Delete an assignment.
    - Request Body: None

15. Grade Assignment
    - Method: PATCH
    - Endpoint: /assignments/grade/:studentAssignmentId
    - Path Param: studentAssignmentId
    - Description: Grade a student's submission.
    - Request Body:
      {
        "score": 95
      }

--- ATTENDANCE ---

16. Get Session Attendance
    - Method: GET
    - Endpoint: /attendance/session/:sessionId
    - Path Param: sessionId
    - Description: Get list of students who marked attendance for a session.
    - Request Body: None

17. Approve Attendance
    - Method: PATCH
    - Endpoint: /attendance/approve/:attendanceId
    - Path Param: attendanceId
    - Description: Approve or reject a student's attendance.
    - Request Body:
      {
        "approved": true,
        "finalStatus": "present"
      }
