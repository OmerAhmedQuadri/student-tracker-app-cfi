# 🎓 Student Tracker App

## 1. Skill Graph / Learning Roadmap

* Skill-wise progress visualization
* Topics covered vs pending
* Current learning stage per skill

---

## 2. Weakness Detection

* Assignment performance analysis
* Time taken to complete topics
* Low activity & broken streak detection

---

## 3. Daily / Weekly Learning Activity Tracking

Track:

* Minutes spent learning
* Learning streak (daily / weekly)
* Number of tasks completed
* Code submissions

---

## 4. External Activity Tracking (Branding)

Track from:

* **GitHub**

  * Commits per week
  * Projects pushed
  * Last activity date
* **LinkedIn**

  * Number of posts
  * Last post date
* **Medium**

  * Blogs published
  * Last blog date

---

## 5. Attendance & Session Tracking (Mentorship)

For each student:

* Sessions attended (first the student's will add the attendence then the metor will approve it later if the student make his/her attendance but not present in the class then  the student will make as )
* Sessions missed
* Sessions cancelled
* Assignment deadlines & status

---

## 6. Leaderboard

Rank students based on:

* Course completion
* Consistency (streak)
* Performance (assignments & tasks)
* Personal branding activity (LinkedIn / Medium)

---

## 7. Notifications & Reminders

Automated alerts:

* *You haven’t posted on LinkedIn this week*
* *You missed 2 assignments*
* *Your JavaScript progress is below average*

---

## 8. Admin / Mentor Dashboard

Mentor can view:

* Batch-level performance overview
* Students falling behind
* Most common weak topics
* Engagement & activity trends
