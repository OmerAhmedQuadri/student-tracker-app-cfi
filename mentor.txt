Mentor API Endpoints and Data Requirements
Base URL: http://localhost:5000/api
Note: All endpoints require an httpOnly cookie "accessToken" obtained from the Login endpoint and the user must have the "mentor" role.

--- ASSIGNMENTS ---

1. Create Assignment
   - Method: POST
   - Endpoint: /assignments
   - Description: Create a new assignment.
   - Request Body:
     {
       "title": "React Basics",
       "skillId": "65a...", // Mongo ID of the skill
       "dueDate": "2023-11-01T23:59:59Z",
       "maxScore": 100
     }
   - Response:
     {
       "_id": "65c...",
       "title": "React Basics",
       "skillId": "65a...",
       "dueDate": "2023-11-01T23:59:59.000Z",
       "maxScore": 100,
       ...
     }

2. Get All Assignments
   - Method: GET
   - Endpoint: /assignments
   - Description: Lists all available assignments.
   - Request Body: None

3. Get Assignment By ID
   - Method: GET
   - Endpoint: /assignments/:id
   - Path Param: id (Assignment ID)
   - Description: Get details of a specific assignment.
   - Request Body: None

4. Update Assignment
   - Method: PATCH
   - Endpoint: /assignments/:id
   - Path Param: id (Assignment ID)
   - Description: Update an existing assignment.
   - Request Body:
     {
       "title": "React Advanced",     // Optional
       "dueDate": "2023-11-05"        // Optional
     }

5. Delete Assignment
   - Method: DELETE
   - Endpoint: /assignments/:id
   - Path Param: id (Assignment ID)
   - Description: Delete an assignment.
   - Request Body: None

6. Get Assignment Submissions
   - Method: GET
   - Endpoint: /assignments/:assignmentId/submissions
   - Path Param: assignmentId
   - Description: Get all student submissions for a specific assignment.
   - Request Body: None

7. Grade Assignment
   - Method: PATCH
   - Endpoint: /assignments/grade/:studentAssignmentId
   - Path Param: studentAssignmentId (ID of the StudentAssignment document)
   - Description: Grade a student's submission.
   - Request Body:
     {
       "score": 95
     }
   - Response: Updated StudentAssignment document.

--- ATTENDANCE ---

8. Get Session Attendance
   - Method: GET
   - Endpoint: /attendance/session/:sessionId
   - Path Param: sessionId (ID of the MentorshipSession)
   - Description: Get list of students who marked attendance for a session.
   - Request Body: None

9. Approve Attendance
   - Method: PATCH
   - Endpoint: /attendance/approve/:attendanceId
   - Path Param: attendanceId (ID of the StudentAttendance record)
   - Description: Approve or reject a student's attendance.
   - Request Body:
     {
       "approved": true,
       "finalStatus": "present" // "present" or "absent"
     }

--- SESSIONS (Mentorship & Learning) ---

10. Create Mentorship Session
    - Method: POST
    - Endpoint: /sessions/mentorship
    - Description: Schedule a new mentorship session.
    - Request Body:
      {
        "batchId": "Batch 1",  // String or ID identifying the batch
        "date": "2023-10-30T10:00:00Z",
        "topic": "Intro to Node.js"
      }

11. Get Mentorship Sessions
    - Method: GET
    - Endpoint: /sessions/mentorship
    - Description: List all mentorship sessions.
    - Request Body: None

12. Update Mentorship Session
    - Method: PATCH
    - Endpoint: /sessions/mentorship/:id
    - Path Param: id (Session ID)
    - Description: Update session details.
    - Request Body:
      {
        "date": "2023-10-31T10:00:00Z",
        "topic": "Node.js & Express"
      }

13. Get Student Learning Sessions
    - Method: GET
    - Endpoint: /sessions/learning/:userId
    - Path Param: userId (Student's User ID)
    - Description: View learning sessions logged by a specific student.
    - Request Body: None

--- NOTIFICATIONS ---

14. Create Notification
    - Method: POST
    - Endpoint: /notifications
    - Description: Send a notification to a user.
    - Request Body:
      {
        "userId": "65a...",
        "type": "info", // "info", "warning", "success", "error"
        "message": "Please submit your assignment."
      }

--- EXTERNAL ACTIVITIES ---

15. Get User External Activities
    - Method: GET
    - Endpoint: /external-activities/:userId
    - Path Param: userId (Student's User ID)
    - Description: View external platform stats (LeetCode, etc.) for a specific student.
    - Request Body: None

--- SKILLS ---

16. Get All Skills
    - Method: GET
    - Endpoint: /skills
    - Description: List all skills.
    - Request Body: None

17. Create Skill
    - Method: POST
    - Endpoint: /skills
    - Description: Create a new skill.
    - Request Body:
      {
        "name": "React",
        "batchId": "Batch A"
      }

18. Delete Skill
    - Method: DELETE
    - Endpoint: /skills/:id
    - Path Param: id (Skill ID)
    - Description: Delete a skill.
    - Request Body: None

19. Create Skill Topic
    - Method: POST
    - Endpoint: /skills/topics
    - Description: Add a new topic to a skill.
    - Request Body:
      {
        "skillId": "65a...",
        "title": "Hooks",
        "difficulty": "intermediate", // "beginner", "intermediate", "advanced"
        "estimatedMinutes": 60
      }

20. Get Skill Topics
    - Method: GET
    - Endpoint: /skills/topics/:skillId
    - Path Param: skillId
    - Description: Get topics for a skill.
    - Request Body: None

21. Update Skill Topic
    - Method: PATCH
    - Endpoint: /skills/topics/:id
    - Path Param: id (Topic ID)
    - Description: Update a topic.
    - Request Body:
      {
        "title": "Custom Hooks",
        "difficulty": "advanced"
      }

22. Delete Skill Topic
    - Method: DELETE
    - Endpoint: /skills/topics/:id
    - Path Param: id (Topic ID)
    - Description: Delete a topic.
    - Request Body: None

23. Get Student Skill Progress
    - Method: GET
    - Endpoint: /skills/progress/:userId
    - Path Param: userId (Student's User ID)
    - Description: Get skill progress for a specific student.
    - Request Body: None
